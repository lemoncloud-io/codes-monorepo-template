# BannerAI

AI-powered banner generator for blog and social media.

## Features
- Content analysis using Gemini 3.1 Flash.
- Image generation with various aspect ratios.
- Visualization of the generation process (input/output steps).
- Support for Blog (16:9) and Social (1:1) formats.

## Tech Stack
- React 18+
- TypeScript
- Tailwind CSS
- Gemini API (google/genai)
- Lucide React Icons
- Motion (framer-motion)

## Setup
1. Clone the repository.
2. Install dependencies: `npm install`
3. Set your `GEMINI_API_KEY` in `.env`.
4. Run development server: `npm run dev`
